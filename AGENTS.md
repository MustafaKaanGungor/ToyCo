# ToyCo — Agent Guide

## Project
Unity 2D URP game (Unity **6000.0.59f2**). Created from `com.unity.template.universal-2d@5.1.0`.

## Scenes
- `Assets/Scenes/GameScene.unity` — main play scene.
- `AbdulScene.unity` / `MustiScene.unity` — developer sandbox scenes; not in build settings.

## Scripts
All under `Assets/_Scripts/`, grouped by system folder (e.g. `InputSystem/`, `UnitSystem/`).

| File | Role |
|---|---|
| `GameEvents.cs` | Static event bus (`OnMoveInput`) |
| `InputHandler.cs` | Wires new Input System → `GameEvents` |
| `PlayeController.cs` | Moves player Rigidbody2D via `GameEvents.OnMoveInput` |
| `MapUnit.cs` | Abstract base for patrol AI + `OnTriggerEnter2D` → `Interact(MapUnit other)` virtual method |
| `InputSystem_Actions.cs` | **Auto-generated** from `Assets/InputSystem_Actions.inputactions` — do not edit |

## Key packages
- **DOTween** (Demigiant) — `DOTWEEN` scripting define already set.
- **Input System** 1.14.2 — action asset at `Assets/InputSystem_Actions.inputactions`.
- **URP** 17.0.4, **Cinemachine** 3.1.6.
- **Unity Test Framework** 1.6.0 available; no tests written yet.

## Workflow
- No custom build/CI scripts — standard Unity Editor workflow.
- `.csproj` / `.sln` files are gitignored (auto-generated by Unity).
- VS Code recommended extension: `visualstudiotoolsforunity.vstuc`.
- Always regenerate `InputSystem_Actions.cs` via the Input Action asset editor, never hand-edit it.
